# Contribuir

Cada MCP deve indicar claramente o serviço, a conta suportada, o método de autenticação e se cada ferramenta é de leitura ou escrita.

Antes de abrir um pull request:

1. Remover credenciais, tokens e dados pessoais.
2. Testar uma leitura real com uma conta de desenvolvimento.
3. Documentar variáveis de ambiente e permissões Google necessárias.
4. Confirmar que erros de autenticação mostram uma ação corretiva.
5. Manter alterações de orçamento e escrita desligadas por omissão.
